# Мамин Дім — лендінг «Педіатр»

Адаптивна сторінка консультації педіатра, зверстана за макетом Figma на HTML, CSS та JavaScript.

## Структура

- `index.html` — основна сторінка;
- `styles.css` — стилі та адаптивні стани;
- `app.js` — меню, слайдери, попапи, вибір часу та відправка форм;
- `send.php` — серверний обробник заявок;
- `thank-you.html` — сторінка після успішної заявки;
- `photos/` — локальні зображення сторінки;
- `config.example.php` — приклад конфігурації Telegram.

## Локальний запуск

Відкрийте `index.html` напряму або запустіть будь-який локальний HTTP-сервер у корені проєкту.

Для роботи форм потрібен сервер з PHP. Скопіюйте `config.example.php` у `config.php`, додайте власні `telegram_bot_token` та `telegram_chat_id` і переконайтеся, що PHP може записувати файл `storage/leads.csv`.

`config.php` і локальний файл із заявками не додаються до Git.
